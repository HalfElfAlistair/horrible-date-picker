## Introduction

A friend sent me the URL for the Bad UX World Cup and I was drawn in immediately. My initial ideas revolved around continually randomising an already annoying click based keyboard (something that made it's way to the final build). After hearing some further interesting suggestions from friends, I decided to work with these and make a three stage date picker (day, month, and year).


### Aims

Instructions from the challenge were as follows:

* Build a date picker with bad UX (the worse, the better)
* Your date picker must make it technically possible to pick the desired date
* Use any technology or web framework
* Make your submission available on a publicly accessible URL

## Launch & Run

This project can be viewed here: [https://horrible-date-picker.netlify.app/](https://horrible-date-picker.netlify.app/).

You can follow [these instructions to clone this repository](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository).

Then access the repo, run npm install and then, once that's done, npm run dev should run a local version of the project.

### Prerequisites:

You may need a recent Node version, I've built in v22.20.0. Otherwise i've kept it fairly basic.

## Notes

There's a sadistic part of me that really enjoyed putting something together that was supposed to frustrate people. It was tough going against my instincts at times though. I've lost count of how many times I had to tell myself not to auto-navigate to the next stage on confirmation. Similarly, when moving to another stage without using the tick button, I've had to resist the urge to prevent the user losing anything they'd painstakingly inputted. I figured leaving these little things untouched would only add to the bad user experience, but it may have hurt me a little to do so (we're all suffering with this project).

Possibly my favourite part of this project is the nav. Setting the order of entry as I have, really made it counter intuitive while using the arrow buttons. Sometimes the best parts just come through organically.
